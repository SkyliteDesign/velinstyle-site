VelinStyle Feature-Umfang 1.2.0

Übersicht über das, was in 1.2.0 enthalten ist — CSS, Web Components, Runtime, CLI, Security und Design Intelligence. Prüfen Sie die Reifegrad-Badges, bevor Sie eine Oberfläche als produktionsreif behandeln. English: Feature scope

Reifegrad

CSS / Web Components / Runtime sind stable. Plan / Review / Agent-Meta sind beta / foundation. Studio und die komplette Utility Engine bleiben planned.

Wann nutzen

  • Diese Seite als 1.2.0-Reifegrad-Karte nutzen, bevor Sie in generierte Referenz oder Guides einsteigen.
  • @birdapi/velinstyle@1.2.0 pinnen und Badges für beta vs. planned prüfen.

Wann nicht

  • Beta Plan/Review/Meta nicht als fertiges KI-Design-System behandeln.
  • Keine noch geplanten Studio- oder Utility-Engine-APIs erfinden.
  • AAA-orientierte Defaults nicht als Anwendungs-Zertifizierung lesen.
